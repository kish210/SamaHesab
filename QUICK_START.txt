    └─ Wait for project load (1-2 min)

2️⃣  RESTORE PACKAGES
    └─ Build → Clean Solution

    └─ Or in Terminal: dotnet restore

3️⃣  CREATE DATABASE
    └─ Open SQL Server Management Studio
    └─ Create new query
    └─ Copy & Execute: D:\duc\sama-hesab\database\01_CreateDatabase.sql
    └─ Copy & Execute: D:\duc\sama-hesab\database\02_CreateTables.sql

    └─ Edit: D:\duc\sama-hesab\src\SamaHesab.WPF\appsettings.json
    └─ Verify: "Server=.;Database=SamaHesab;Trusted_Connection=True;"

5️⃣  RUN APPLICATION
    └─ In Visual Studio: Right-click SamaHesab.WPF → Set as Startup Project
