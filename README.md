# سامانهٔ جامع «سما حساب» — نسخهٔ ۲.۶.۵

> یک نرم‌افزار **حسابداری و مدیریت کسب‌وکار (ERP)** کاملِ فارسی، راست‌به‌چپ، با تقویم شمسی — در سطحِ سپیدار/هلو/راهکاران (SMB).
> معماری مبتنی بر **سرور مرکزی (Web API)**: کلاینت‌ها از طریق شبکه به سرور وصل می‌شوند، نه مستقیم به پایگاه‌داده.

> **🆕 تازه در ۲.۶.۵:**
> - **فروشِ گردشگریِ فروشنده‌محور:** سیستم فروشنده را **خودکار از کاربرِ لاگین‌شده** تشخیص می‌دهد (نگاشتِ کاربر→فروشنده در «امنیت ← کاربران»)؛ فروشنده‌ها فقط به‌نامِ خودشان ثبت می‌کنند، مدیر آزاد است.
> - **نسخه‌گذاریِ هر ماژول:** در «مدیریت ماژول‌ها» نسخهٔ در حالِ اجرای هر ماژول دیده می‌شود تا بعد از آپدیت معلوم باشد کدام نسخه فعال است؛ **وب و موبایل** هم به‌عنوان ماژولِ مستقل اضافه شدند.
> - **میانبرِ هوشمندِ دسکتاپ:** نصاب فقط میانبرِ «سما حساب» می‌سازد؛ میانبرِ هر ماژول **هنگامِ فعال‌شدنش** خودکار روی دسکتاپ می‌آید و با غیرفعال‌شدن حذف می‌شود.
> - ثبتِ دائمیِ **بهای تمام‌شدهٔ کالای فروش‌رفته (COGS)** در سندِ فروش · درجِ **QR** در PDFِ بومی · رفعِ ایرادهای صفحهٔ «مدیریت ماژول‌ها» و منوی گردشگری.
>
> **۲.۶.۰ (پلتفرمِ ماژولار):** دامنه‌های اختیاری (هتل/پیمانکاری/رستوران/گردشگری/POS/CRM/منابع‌انسانی/حضوروغیاب) به‌صورتِ ماژولِ قابلِ روشن/خاموش پشتِ یک قراردادِ واحد استخراج شدند؛ هسته بدونِ هر ماژول کامل کار می‌کند · بازارِ ماژول‌ها + بارگذاریِ runtime.
>
> **۲.۵.۱۲–۲.۵.۱۹ (ماژول‌های تخصصیِ تازه):**
> - **حقوق و دستمزدِ کامل (قانونِ کار):** پایه/سنوات/حق‌مسکن/بن/اولاد + اضافه‌کاری/شب‌کاری/جمعه‌کاری + بیمهٔ ۷٪ کارمند و ۲۳٪ کارفرما + مالیاتِ پلکانی + محاسبهٔ دسته‌ای + فیشِ چاپ + خروجیِ لیستِ بیمه/مالیات/بانک.
> - **حضور و غیاب:** ثبتِ ورود/خروج + علامت‌گذاریِ دسته‌ای + مرخصی + ایمپورتِ دستگاه/اکسل + تجمیعِ ماهانه که مستقیماً به حقوق تزریق می‌شود.
> - **گردشگری (مدلِ ودیعهٔ تأمین‌کننده):** ثبتِ فروش با سود/پورسانتِ زنده و سندِ متوازن + ودیعهٔ تأمین‌کنندگان (مانده/شارژ/هشدار) + پورسانتِ فروشندگان + گزارش‌ها.
> - **پیمانکاری:** صورت‌وضعیت با **آبشارِ زندهٔ کسورات** (بازیافتِ پیش‌پرداخت/حسن‌انجام/بیمه/مالیات) + سندِ متوازنِ خودکار + پیش‌پرداخت/ضمانت‌نامه + داشبوردِ پروژه.
> - **نصابِ ماژولی:** هنگامِ نصب، بخش‌های موردِ نیاز انتخاب می‌شوند و **میانبرِ دسکتاپ تنها برای همان‌ها** ساخته می‌شود.
> - **فعال‌سازیِ آنلاین از سایت** + خروجیِ اکسلِ گزارش‌های باگ در پنلِ پشتیبانیِ وردپرس.
>
> **۲.۵.۸–۲.۵.۱۱ (تجربهٔ کاربری):**
> - **جست‌وجوی سراسری (Ctrl+K):** یک جعبه برای یافتنِ فوریِ مشتری/کالا/فاکتور/حساب/چک در سراسرِ برنامه + **Command Palette** برای اجرای هر عملیات از صفحه‌کلید.
> - **دسترسیِ سریع:** نوارِ «صفحاتِ اخیر/سنجاق‌شده» + **میان‌برهای استانداردِ یکپارچه** (F2 جدید · F3 جست‌وجو · F5 بازخوانی · F9 ثبت · Ctrl+S/Ctrl+P) با **راهنمای میان‌بر (F1)**.
> - **نمای انبار:** صفحهٔ عملیاتیِ یکپارچهٔ انباردار (کسری/زیرِ حداقل/ارزشِ موجودی + فهرستِ اقلامِ نیازمندِ توجه).
> - **فروش/خرید هوشمند:** **تاریخچهٔ قیمت** (آخرین قیمتِ فروش/خرید به همین طرف)، **خریدهای اخیرِ مشتری/تأمین‌کننده** (افزودنِ یک‌کلیکی)، **پرداختِ ترکیبی** (نقد+کارت+نسیه)، اتصالِ **کارت‌خوانِ بانکی (POS)**، بازکردنِ فاکتورِ ثبت‌شده، پیش‌فاکتور.
> - **منوی راست‌کلیک** روی فهرست‌ها و گریدها (مشتری/کالا/تأمین‌کننده/اقلامِ فاکتور → کارت/صورت‌حساب/تکرار/حذف).
> - **ویزاردِ راه‌اندازیِ هوشمند:** انتخابِ ماژول‌های موردِ استفاده در همان ابتدا + رفعِ ذخیره‌نشدنِ فیلدهای مشتری.
>
> **۲.۵.۰–۲.۵.۷:** معماریِ کاملِ **API-only** · **طرف‌حسابِ یکپارچهٔ چندنقشه** (`Crm.Parties`) · **مرکزِ پشتیبانیِ مشتری** (تیکت/باگ/دانش‌نامه/عیب‌یابی/ریموت + پلاگینِ وردپرس) · بوت‌استرپِ خودکارِ DB + جداسازیِ چندشعبه + به‌روزرسانیِ خودکار از گیت‌هاب.
>
> **۲.۴.۰:** مجموعهٔ کاملِ گزارش‌های مدیریتی (ماندهٔ سنی‌شده، خلاصهٔ مالیات، دفتر روزنامه، سود کالا، کالای راکد، تحلیل ABC، گردش موجودی) · قفلِ دورهٔ مالی · کاملیِ حسابرسی · بکاپِ زمان‌بندی‌شده.

> این نصابِ تک‌سیستمی کلاینتِ حسابداری + POS/رستوران + سرورِ API را با هم نصب می‌کند. برای استقرارِ سرور/کلاینتِ جداگانه، بخشِ «نصب و راه‌اندازی» را ببینید.

## ✨ امکانات

### هستهٔ حسابداری
- **ثبت سند** کیبوردمحور (F2/F7/F8/F9 + توازنِ خودکار)، با حساب‌های اخیر/موردعلاقه، الگو و کپیِ سند، **ورودِ انبوه از اکسل**، و **عدم قطعی تا تراز شدن**.
- **اسناد حسابداری** با master-detail، فیلترِ بازه/نوع/وضعیت، و خروجیِ اکسل/چاپ.
- **نمودار حساب‌ها** درختی با جستجو، **ماندهٔ واقعی (roll-up به والدها)** و **drill-down به دفتر کل**.
- گزارش‌های مالی: **تراز آزمایشی، دفتر کل/معین، سود و زیان، ترازنامه، صورت جریان وجوه نقد** — با فیلترِ شعبه/مرکزهزینه/پروژه و خروجیِ اکسل/PDF.
- مرکز هزینه، پروژه، سال مالی (با قفلِ دوره)، سند معکوس، بستنِ سال مالی.

### خزانه‌داری
- **مدیریت چک** با کارت‌های آماری، چرخهٔ وضعیت (وصول/واگذاری/برگشت با سند خودکار)، هشدارِ سررسید و منوی راست‌کلیک.
- صندوق/بانک، **مغایرت‌گیری بانکی**، دریافتنی/پرداختنی با تخصیص خودکار FIFO، **تسویهٔ بین‌شعبه**.

### فروش · خرید · انبار
- فاکتور فروش/خرید (فضای‌کاریِ کیبوردمحور + بارکد-اول)، **تاریخچهٔ قیمت**، **خریدهای اخیر**، **پرداختِ ترکیبی + کارت‌خوان**، **مرجوعی**، پیش‌فاکتور، لیست‌قیمت و **تخفیفِ پلکانی**.
- مانده/صورت‌حسابِ مشتری و تأمین‌کننده، **کنترلِ سقفِ اعتبار**، کارتِ ۳۶۰°، باشگاه مشتریان.
- انبار: **نمای انبار**، کاردکس، انتقال بین‌انبار، **انبارگردانی سندی**، بچ/سریال/انقضا، بهای تمام‌شدهٔ **میانگین موزون و FIFO**.

### امنیت · چندشعبه · داشبورد
- **نقش‌ها و مجوزهای دانه‌ریز (RBAC)** + JWT · چندشعبه با جداسازیِ داده · **داشبورد نقش‌محور** (مدیر/حسابدار/انباردار/صندوق/فروشنده).

### ماژول‌های اختیاری
- صندوق فروشگاهی **POS** (لمسی، شیفت/Z-X، Hold/Recall، پرداختِ ترکیبی) · **رستوران** (میز/گارسون/آشپزخانه) · CRM · **مرکزِ پشتیبانیِ مشتری** + پلاگینِ وردپرس.
- **حقوق و دستمزد** + **حضور و غیاب** (قانونِ کار، بیمه/مالیات، فیش و لیست‌های قانونی) · **گردشگری** (مدلِ ودیعه، پورسانت) · **پیمانکاری** (صورت‌وضعیت با آبشارِ کسورات، پیش‌پرداخت/ضمانت‌نامه).
- هر ماژول هنگامِ نصب یا از «تنظیمات ▸ مدیریت ماژول‌ها» قابلِ روشن/خاموش است.

## 🚀 نصب و راه‌اندازی (کاربرِ نهایی)

نصاب‌های نسخهٔ ۲ **خودکفا** هستند (به نصبِ جداگانهٔ .NET نیاز ندارند). تنها پیش‌نیازِ سرور، **SQL Server** است.

### ۱) سرور (یک‌بار، روی سیستمِ مرکزی)
1. **SQL Server 2019/2022** (Express یا بالاتر) را نصب کنید.
2. نصابِ سرور را اجرا کنید: **`SamaHesab_Server_Setup.exe`** — در ویزارد، نامِ سرورِ SQL (مثلاً `.\SQLEXPRESS`) و نامِ پایگاه‌داده (`SamaHesab`) را وارد کنید.
3. **نیازی به اجرای دستیِ اسکریپت نیست.** در اولین اجرا، برنامه خودش پایگاه‌داده + schemaها + جدول‌ها + دادهٔ پایه (نمودار حساب‌ها، شرکت/شعبه/سالِ مالی، کاربرِ `admin`) را می‌سازد و مهاجرت‌های افزایشی را idempotent اعمال می‌کند.
4. سرویسِ Web API روی `http://<آی‌پی‌سرور>:5080` بالا می‌آید.

### ۲) کلاینت (روی هر سیستمِ کاربر)
1. نصابِ کلاینت را اجرا کنید: **`client.exe`**.
2. در ویزارد، **آدرس سرور** (`http://<آی‌پی‌سرور>:5080`) و **شناسهٔ شعبه** را وارد کنید.
3. در نخستین اجرا، **ویزاردِ راه‌اندازی** ماژول‌های موردِ استفاده + اطلاعاتِ شرکت/سالِ مالی را می‌پرسد.

> **یا** برای نصبِ تک‌سیستمی (سرور+کلاینت روی یک دستگاه): **`SamaHesab_Setup_v2.6.5.exe`**.

### ورودِ پیش‌فرض
```
نام کاربری: admin
گذرواژه:   admin123
```
> ⚠️ پس از نخستین ورود، گذرواژه را از همان ویزارد تغییر دهید و کلیدِ `Jwt:Key` در `appsettings.json`ِ سرور را عوض کنید.

### حالت‌های اجرا
`SamaHesab.exe` (حسابداری) · `--pos` فروشگاه · `--restaurant` رستوران · `--waiter` گارسون · `--kitchen` آشپزخانه · `--warehouse` انبار.

📘 راهنمای کاملِ کاربر و خودآموزِ تصویری همراهِ نصاب توزیع می‌شوند (`docs/`).

## 🧱 معماری و فناوری
- **.NET 9 / WPF** (دسکتاپ، RTL، فونت Vazirmatn) · **ASP.NET Core Web API** (JWT) · **EF Core / SQL Server**.
